## 三、规划建议

### 1. 唯一的"分发阻塞项"该还了：真签名 + 公证（半天）
ad-hoc 签名意味着 DMG 发给任何人都会被 Gatekeeper 拦。需要 Apple Developer 账号（$99/年）+ Developer ID 证书 + `notarytool`。做完这条，"可分发"才从口号变成事实——它排在一切新功能前面。

### 2. 智能脱敏（1–2 天）：AI 叙事的第一块实体
所有零件已就位（OCR 返回坐标、RedactionShape 可编程生成、历史/导出管线稳定）。正则匹配手机号/邮箱/身份证/API Key → 命中位置自动生成打码对象，用户可再调整。这是"会理解内容的截图工作台"定位下第一个用户可感知的 AI 功能，且天然衔接"截图→发帖"场景。

### 3. 补齐"手感层"（合计 3–4 天，日用口碑）
方向键微调选区（半天）· 延时截屏（半天）· 选区时窗口吸附高亮（1–2 天，冻结帧 + 冻结时刻的 CGWindowList 边界即可实现，不用实时捕获）· 直线/画笔/记号笔（各半天，画笔走点集对象）。这些是 Snipaste 免费版用户的肌肉记忆，缺一项就少一个"设为默认"的理由。

### 4. 语义理解开动（1–2 周）：定位的命脉
OCR 之后 AI 停滞了。最小可行路径：设置里接 OpenAI 兼容端点（用户自带 Key）+ 本地 Ollama 可选 → 工具栏"问这张图"→ 选中区域/整图 → 结果侧栏（可复制）。紧扣三个场景：报错解释、代码提取、界面说明。**默认本地优先、敏感截图不上云**照旧是卖点。这一步做完，"AI"才从 OCR 一个点变成一条线。

### 5. Pin 鼠标穿透（1 天）
Snipaste 伪透明的核心手感（透明区域点击穿过）。自定义 content view hitTest 读 alpha 即可，此前可行性分析已给过路径。

### 6. 结构性想法：把"截图后动作"数据化
取色、OCR、脱敏、贴图、复制、上传……本质都是 `CaptureRequest → [ExportTask]`。可行性分析提过的 CaptureRequest/ExportTask 模型值得在做第 4 项之前先立起来——它是未来"工作流自动化 + 插件系统"（阶段三）的地基，现在加动作的成本最低。

### 7. 战略层
- **商业化分层已经自然成形**：免费 = Snipaste 免费版水平 + 二次编辑（已超）；Pro = AI 线（脱敏/理解/提取）+ 历史无限制。不用急着定价，先把免费线做到"敢推荐给同事"。
- **多屏完整交互**仍是最大的平台正确性债务，在多屏用户投诉出现之前优先级可以低于上面所有项。
- 验收标准照旧：能连续一周把它设为默认截图工具不切走；出现"只能用 AISnap 做"的场景（脱敏上线后第一个候选：截一张带 token 的报错图 → 一键打码 + 复制代码 + 中文解释）。
