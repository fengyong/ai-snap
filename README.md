# AISnap

macOS 原生截图标注工具，基于 Swift + AppKit 构建，支持丰富的标注功能和直观的交互体验。

## 功能列表

### 截图捕获
- **区域截图** - 全屏覆盖层，鼠标拖拽选择任意矩形区域
- **窗口截图** - 自动检测鼠标下方的窗口并捕获
- **Retina 适配** - 自动识别屏幕 DPI，正确处理 2x/3x 分辨率
- **先冻屏、再选区** - 显示覆盖层**之前**先截一次屏，覆盖层画的是冻结帧。
  于是选区确定只需裁一刀：不必等覆盖层消失，也不可能把覆盖层自己拍进去
- **就地进入标注** - 标注画布精确压在刚框住的选区上，四周保持变暗，没有窗口跳变

### 标注工具
- **箭头** - 拖拽绘制，支持 8 种预设样式（实心、开放、虚线、菱形、圆端、点菱、**双向**、**双开放**）
- **矩形 / 圆角矩形** - 拖拽绘制；圆角半径随线宽缩放（否则会被线宽填满、看不出圆角）
- **圆形 / 椭圆** - 拖拽绘制，宽高可独立
- **序号** - 单击放置带数字的圆形标记，编号自动递增；**删除后其余自动重排**（1、2、3… 不会跳号）
- **文字** - 单击直接输入，回车确认；**双击已有文字可重新编辑**
- **聚光灯** - 框选高亮区域，其余区域自动变暗，支持多个叠加
- **马赛克 / 高斯模糊** - 拖拽框选打码。直接读原始截图像素，与已画的标注无关；
  取样区域用形状的外接矩形，所以旋转后覆盖依然完整、不会漏出原文
- **橡皮擦** - 拖拽抹掉经过的对象；**整笔拖拽合并为一步撤销**
- **表情贴纸** - 18 个预设表情/符号，单击放置到画布上

### 取色器
- 11×11 放大镜跟随鼠标，实时显示 HEX 与 RGB
- 单击即把颜色设为当前颜色，并把 `#RRGGBB` 复制到剪贴板
- 取的是**原始截图**的颜色（不包含已画上的标注），所以"这个位置是什么颜色"有确定答案

### 文字识别（OCR）
- 系统自带 Vision，**完全离线、免费、不需要账号**
- 结果按阅读顺序（先上后下、同行先左后右）拼好复制到剪贴板
- 识别到的位置会在画布上框出来，按 Esc 清除
- 坐标换算没有 Y 翻转（Vision 与画布都是左下原点）—— 这点和另外两处换算相反

### 截图历史
- 每次截图都会留一份**原图**（含没有保存的），最多保留最近 30 张
- 列表可「打开（重新编辑）/ 复制 / 显示 / 删除」，可一键清空
- 索引与磁盘文件同步清理；文件被外部删掉时索引会自愈

### 贴图（Pin）
- 把当前画面钉在屏幕上，可拖动、滚轮缩放、双击关闭
- **透明区点击穿透**：带 alpha 的图，透明像素上的点击/拖动会落到下面的窗口
- **右键菜单**：复制到剪贴板 / 保存为文件 / 不透明度（100–20%）/ 实际大小
- 设置了 `.canJoinAllSpaces + .fullScreenAuxiliary`：切到全屏应用时贴图不会消失
- `sharingType = .none`：贴图自己不会被后续截图拍进去

### 对象编辑
- **选择与移动** - 双图层 Color Picking 方案，点击精确选中对象，拖拽移动
- **取消选中** - 按 ESC 取消当前选中，恢复绘制模式
- **旋转** - Option + 拖拽旋转选中对象
- **缩放** - Shift + 拖拽缩放选中对象
- **删除** - Delete 键或点击右上角红色 X 按钮删除
- **撤销/重做** - Cmd+Z 撤销，Cmd+Shift+Z 重做，支持所有操作（添加、删除、移动、旋转、缩放）
- **选中特效** - 蓝色发光虚线边框 + 四角手柄 + 右上角删除按钮

### 智能辅助
- **点吸附** - 绘制时自动吸附到附近对象的端点、中心、角点、边中点（12px 阈值）
- **被动吸附指示器** - 鼠标悬停时实时显示最近吸附点，十字 + 菱形可视化提示
- **中心点绘制** - 起点吸附到已有对象时，以吸附点为中心向外绘制圆形/椭圆/矩形
- **对象附着** - 箭头端点可附着到形状周长，父对象移动/旋转/缩放时箭头自动跟随
- **级联删除** - 删除父形状时自动删除附着的箭头

### 颜色与样式
- **5 套调色板** - 鲜明、专业、柔和、高对比、灰度，一键切换
- **线宽 / 线型** - 实线 / 虚线 / 点线，对矩形、椭圆、箭头都可用
- **箭头样式** - 8 种预设箭头头部/尾部/线型组合（含双向、双开放）
- **偏好自动记住** - 线宽、颜色、线型、箭头样式、调色板、水印、上次用的工具
  都会跨重启保留（状态栏菜单 →「恢复默认设置」可回到出厂值）

### 水印
- **文本水印** - 可配置水印文本内容
- **平铺模式** - 自动以 -30 度角平铺覆盖全图
- **导出时渲染** - 仅在保存/复制时叠加，不影响编辑

### 键盘与全局入口
- **全局快捷键** - 默认 `⌃⌘A` 区域截图、`⌃⌘W` 窗口截图，任何应用前台都能唤起
  （可在偏好设置里改键；注册前会拦下系统截图的组合）
- **标注阶段全程不碰鼠标** - `Enter` 复制并关闭 / `⌘C` 复制 / `⌘S` 保存 /
  `Tab` `⇧Tab` 循环切工具 / `1`~`9` 直选工具 / `Esc` 取消 / `Delete` 删除 /
  `⌘Z` `⇧⌘Z` 撤销重做 / `F3` 贴图

### 导出
- **保存为 PNG** - 通过系统保存面板选择路径（写盘失败会明确提示原因，不静默吞掉）
- **复制到剪贴板** - 同时写入图片内容与图片文件，既可直接粘贴也能在访达里 ⌘V 存成 .png

### 界面
- **状态栏常驻** - 不占 Dock
- **直观工具栏** - 中文文字按钮 + 分组标签 + 悬浮提示；一行放不下时**按组折行**
  （工具栏内容接近 1.5k 点宽，若用来撑宽窗口，窗口就会比屏幕还宽，
  就地编辑只能整体左移、画布离开选区）
- **偏好设置窗口** - 全局快捷键 / 开机自动启动 / 截图历史 / 检查更新
- **帮助对话框** - 详细的功能使用说明
- **Debug 面板** - 默认隐藏，`⌘D` 开关；显示 Layer B (Hit Test) 的实时可视化

|------|------|
| `main.swift` | 应用入口 |
| `AppDelegate.swift` | 状态栏菜单、截图调度、历史与更新的入口 |

| `Models.swift` | 数据模型与全部标注对象类 |
| `HitTestBuffer.swift` | 离屏 Hit Test 缓冲区（唯一颜色 Key 方案） |
| `Redaction/` | 打码：纯图像处理 + 打码对象 |
| `Picker/` | 取色器：底图像素采样与坐标换算 |
| `OCR/` | 本地文字识别（Vision）与阅读顺序 |
| `History/` | 截图历史：索引 + 磁盘文件 |
| `Pin/` | 贴图置顶 |
| `Preferences.swift` / `SettingsWindow.swift` | 偏好持久化与设置窗口 |
| `HotkeyManager.swift` / `LaunchAtLogin.swift` | 全局快捷键、开机启动 |
| `Update/` | 更新检查（版本号比较、清单地址校验） |

**截图捕获的分工**

```
决定「截哪个」  →  ScreenCapture.swift（CGWindowListCopyWindowInfo，未废弃）
真正「抓图」    →  CaptureProviderSCK（ScreenCaptureKit）
```

两者通过 `CGWindowID` 对接（`SCWindow.windowID` 的类型就是 `CGWindowID`），
所以窗口命中判定逻辑无需改动，只替换最终的抓图调用。

> 旧的 `CGWindowListCreateImage` 自 macOS 14.0 起 deprecated、15.0 起 obsolete，
> 因此本项目最低支持 macOS 14，抓图统一走 ScreenCaptureKit。

**核心设计：双图层 Color Picking**
- Layer A（可见层）：正常渲染所有标注对象
- Layer B（隐藏层）：每个对象用唯一颜色绘制，鼠标点击时读取像素颜色即可精确识别对象

## 构建、打包与安装

**要求：** macOS 14+，Swift 5.9+（开发需要 Xcode 或 Command Line Tools）

### 开发时直接跑

```bash
swift run AISnap
```

### 打包成安装包

```bash
./build.sh              # 产出 AISnap.app 与 AISnap.dmg
./build.sh --skip-dmg   # 只要 .app
```

脚本会：校验版本号一致 → `swift build -c release` → 组装 .app（含 Info.plist 与图标）
→ **ad-hoc 签名并校验** → 打 DMG → **挂载 DMG 复验包内应用与签名**。

> 在已被沙箱包裹的环境里（CI 容器、自动化工具）SwiftPM 给清单套的那层 sandbox-exec
> 会失败，加 `SWIFT_FLAGS=--disable-sandbox` 即可。默认不关 ——
> 那层沙箱是为了防止恶意 `Package.swift` 在构建期乱来。

### 安装

1. 双击 `AISnap.dmg`
2. 把 **AISnap** 拖进「应用程序」
3. 从「应用程序」启动（它常驻状态栏，不占 Dock）
4. 首次启动会请求**屏幕录制**权限 → 到
   `系统设置 → 隐私与安全性 → 屏幕录制` 里勾上 AISnap，**然后重启一次 AISnap**
   （权限生效需要重启应用）
5. 之后按 `⌃⌘A` 就能截图

### 关于屏幕录制权限反复失效

**症状**：在系统设置里勾上了 AISnap，下次启动或下次截图却又要求授权。

**根因是签名方式，不是权限逻辑**（代码里 `if !CGPreflightScreenCaptureAccess()`
只在预检失败时才请求，是标准写法）：

- **ad-hoc 签名没有证书标识**，TCC 只能按 **cdhash** 认应用 —— 而 cdhash 是二进制
  内容的哈希，**每重新编译一次就变**，授权随之失效。
- 更麻烦的是**多份副本**会各自成为一个「应用」：`/Applications` 一份、构建目录一份、
  DMG 卷里一份、`.build/release/AISnap`（裸可执行文件，Identifier 是 `AISnap`
  而非 `com.aisnap.app`，是完全独立的身份）。换种方式启动就是另一个应用。

**立刻可用的三步**：

1. 系统设置 → 隐私与安全性 → 屏幕录制：把 AISnap 的**所有条目删掉**（可能有多条，
   对应不同的 cdhash）
2. 从「应用程序」启动，重新授权
3. **完全退出再启动** —— 屏幕录制权限需要重启应用才生效

之后**只从「应用程序」启动**；`.build/release/AISnap` 仅用于开发调试。

**根治（不需要 Apple Developer 账号）**：

```bash
./scripts/make_signing_cert.sh    # 生成并导入一张自签名代码签名证书
./build.sh                        # 之后会自动用它签名
```

有了稳定的证书标识，TCC 改为按「证书 + bundle ID」关联，重新编译不再影响授权。

> 自签名证书只解决**本机**的权限稳定性。要把 DMG 发给别人的 Mac，
> 仍然需要 Developer ID 证书 + 公证（M5-1）—— 自签名会被 Gatekeeper 拦下。

### 日常使用的几点提醒

- **开机自动启动**：偏好设置里打开这个开关，就不用每次重启后手动启动
  （它需要从「应用程序」里的 AISnap 使用，直接跑构建产物时该开关不可用）
- **不要频繁重装**：当前是 ad-hoc 签名，授权对象包含二进制哈希 ——
  重新编译安装后，屏幕录制权限可能需要再勾一次。装好后正常使用不受影响
- **从旧版本升级后，快捷键可能还是旧值**：偏好一旦存过就不会被新的默认值覆盖。
  旧默认 `⇧⌘W` 会抢掉浏览器的「关闭窗口」，建议到「偏好设置 → 全局快捷键」重录，
  或用状态栏菜单的「恢复默认设置」一次性重置
- **未做签名与公证**：本地打包的 DMG 没有 quarantine 标记，Gatekeeper 不会拦。
  但**不要通过网络/网盘传给别人的 Mac** —— 那样会被拦下。
  这一项（M5-1）需要 Apple Developer 账号，见 `AISnap-下一步开发计划.md`

## 回归测试（离屏探针）

```bash
./probes/run_all.sh              # 16 个探针，约 350 条断言
./probes/run_all.sh redaction    # 只跑名字里含 redaction 的
```

探针**链接真实源码**（不是复刻逻辑），覆盖那些"错了不会报错、只是结果不对"的地方：
坐标方向与倍率反推、版本号比较、撤销粒度、打码的块平均与插值质量、每帧绘制成本上限。
详见 `probes/README.md`。

## 代码统计

约 9,100 行 Swift / 39 个源文件，**无第三方依赖**（截图用系统 ScreenCaptureKit、
快捷键用 Carbon、OCR 用 Vision、模糊用 CoreImage）。
另有 16 个离屏探针（约 2,500 行）与 `scripts/make_icon.swift`（图标由代码生成，
不存来路不明的二进制资源）。
